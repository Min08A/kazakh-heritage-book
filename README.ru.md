# Kazakh Heritage — интерактивная книга (как задеплоить)

Книга с перелистыванием страниц: 8 глав (Домбыра, Юрта, Кобыз, Саукеле, Шапан, Бесбармак, Бесик, Торсык). В каждой главе слева видео и QR-код, справа текст. **QR появляется только когда видео реально доиграло до конца.** QR ведёт на `/object/<slug>` — мобильную страницу с 3D-моделью, озвучкой и транскриптом.

Сборки нет: это обычные файлы (HTML + JS-модули), `npm` не нужен.

## Проверить у себя
```bash
python3 serve.py 8000      # открыть http://localhost:8000
```
На localhost рядом с QR будет жёлтое предупреждение «Testing mode» и кнопка «DEV: simulate end» под видео — на настоящем домене они исчезают сами.

## Деплой

Сайт должен лежать **в корне домена** (`https://имя.vercel.app/`), потому что QR ведёт на `/object/<slug>`.

**Vercel** (проще всего)
1. Загрузите папку в репозиторий GitHub (или в папке выполните `npx vercel`).
2. На vercel.com: *Add New → Project* → выберите репозиторий. Framework Preset: **Other**, Build Command и Output Directory — пустые.
3. Нажмите *Deploy*. Правило `/object/:slug → /object.html` уже в `vercel.json`.

**Netlify**
- Перетащите всю папку на https://app.netlify.com/drop — готово. Или подключите репозиторий (build command пустой, publish directory `.`). Правила лежат в `netlify.toml` и `_redirects`.

**Cloudflare Pages** — подключите репозиторий, Framework preset: None, build command пустой, output directory `/`.

GitHub Pages не подойдёт (нет перенаправления `/object/<slug>`).

## Проверка после деплоя
1. Откройте `https://ВАШ-ДОМЕН/object/dombra` напрямую — должна открыться страница 3D, а не 404.
2. Откройте книгу, досмотрите любое видео до конца — появится QR **без** жёлтого предупреждения. Наведите телефон.
3. По желанию в `js/config.js` задайте `PUBLIC_SITE_URL = 'https://ваш-домен'` — тогда QR всегда будет вести на этот адрес. Если адрес не публичный https, покажется предупреждение.

## Что менять
- Тексты, ссылки на модели, авторы и лицензии — `js/data.js`.
- Видео — `media/videos/<slug>.mp4` + `.webm` (сейчас это сгенерированные анимации с музыкой, **без голоса**).
- Озвучка: положите `media/audio/<slug>.mp3`, и он будет использован. Без файла страница читает транскрипт встроенным английским голосом браузера (так и подписано).
- 3D: Dombra и Kobyz — Sketchfab (CC BY 4.0, Q3D_Library); Yurt, Saukele, Besik — Sketchfab, **лицензия на страницах моделей не указана** — уточните у авторов до публичного запуска. Для всех 8 объектов есть и собственные упрощённые модели в `models/` (кнопка «Use simplified model»); у Shapan, Beshbarmak, Torsyk это основная модель.
